# flash-card

This project is an interactive Flashcard Learning Application designed to streamline language acquisition between French and English. It presents users with French vocabulary words and challenges them to recall the English translation before the answer is revealed.

The app features a simple but effective binary feedback system: users click a green tick if they successfully remembered the word or a red cross if they did not. This intuitive interface allows for rapid self-assessment, helping students focus their study time on the specific vocabulary that remains difficult to master.
